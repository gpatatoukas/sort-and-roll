# Google Play upload assets

Upload these files in **Grow users → Store presence → Main store listing → Graphics**.

| Play Console field | File | Size / format |
| --- | --- | --- |
| App icon | `app-icon-512.png` | 512 × 512, 32-bit RGBA PNG |
| Feature graphic | `feature-graphic-1024x500.jpg` | 1024 × 500, opaque JPEG |
| Phone screenshots | the six PNGs in `phone-connected/` | 1080 × 2160 PNG, six coordinated panels |

The six `phone-connected` images form a continuous dark panorama. They lead with Journey gameplay, then show Daily and Weekly play, mode selection, customization, and the pouring tools. App screens are cropped at their original scale with no device frame.

The app icon is exported from `assets/branding/user-icon.png`. `source/feature-graphic-master.png` is the original promotional artwork; upload the exact-size JPEG instead.

Reference: https://support.google.com/googleplay/android-developer/answer/9866151
