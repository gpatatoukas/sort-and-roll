# Google Play assets

- `app-icon-512.png`: 512 × 512 opaque RGB PNG.
- `feature-graphic-1024x500.png`: 1024 × 500 opaque RGB PNG.
- `phone-drafts/`: six 1080 × 1920 captures of the actual web game at phone
  size. They are useful for review, but are not native Android screenshots and
  should not be uploaded as final screenshots.

The Android emulator is available, but Sort and Roll is not installed on it yet.
Capture the same six screens from a native Android build before submitting the
Play listing. Order: home, relaxed dark, relaxed light, daily puzzle, weekly
journey, hidden colours.

Specification checked 18 October 2026:
https://support.google.com/googleplay/android-developer/answer/9866151
