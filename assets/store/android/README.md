# Google Play upload assets

Upload these files in **Grow users → Store presence → Main store listing → Graphics**.

| Play Console field | File | Size / format |
| --- | --- | --- |
| App icon | `app-icon-512.png` | 512 × 512, 32-bit RGBA PNG |
| Feature graphic | `feature-graphic-1024x500.png` | 1024 × 500 PNG |
| Phone screenshots | the six PNGs in `phone-connected/` | 1080 × 2160 PNG, six coordinated panels |

The six `phone-connected` images are coordinated purple promotional panels built around current Android app captures. They show Journey gameplay, Daily and Weekly play, mode selection, customization, and a second gameplay view. Each panel uses concise English copy and a subtle rounded screen frame.

The app icon is exported from `assets/branding/app-icon-1024.png`. The feature graphic is the current purple branded artwork, resized to the Play Console dimensions above.

Reference: https://support.google.com/googleplay/android-developer/answer/9866151
