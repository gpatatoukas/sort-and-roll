# App Store assets

- `app-icon-1024.png`: 1024 × 1024 opaque RGB PNG for review and upload. It is
  exported from the same source as the runtime icon in `assets/branding/`.
- `iphone/`: six real iPhone 17 Pro simulator captures, 1206 × 2622 opaque RGB
  PNG. They show the home screen, relaxed mode in both themes, daily puzzle,
  weekly journey and a challenge with hidden colours. The banner ad is hidden in
  these store screenshots. The simulator save was restored after capture.

The current configuration is iPhone only. There are no iPad screenshots or
preview video; neither is part of this iPhone asset set. Apple does not require a
feature graphic. Rebuild the native app to update the installed launcher icon
and launch screen.

Specification checked 18 October 2026:
https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/
